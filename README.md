# Dagdan Tehnologiýa landing page

Landing page built with React, TypeScript and Vite, with Turkmen, Russian and
English text.

```bash
npm ci
npm run dev      # local development
npm run build    # production build in dist/
```

The build is served from `/landingv2/`; change `base` in `vite.config.ts` to
host it somewhere else.
